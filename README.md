# Uber Driver Dashboard - C51 G version

Assignment 5 (Product Analytics), AI PM program. A single-file prototype of a driver dashboard that helps an Uber driver earn more per online hour, with wellbeing treated as a constraint.

Open `index.html` in a browser. No build step. All data is mock and seeded.

## What it shows
- Primary metric: earnings per online hour.
- Three scenarios: demand building near an offline driver, a Gold driver with event slots, and a forced 10-hour cool-down.
- Four tabs: Home, Earnings, Opportunities, Menu.
- Live demand map, shift breakdown (zone and time, market today, your driving), gold event slots with accept and decline, and a 10-hour shift cap with a 7-hour rest.
